## Τι περιλαμβάνει
- 📚 Μαθήματα & σχολικά βιβλία (σύνδεσμοι ebooks.edu.gr)
- 🎓 Πανελλήνιες / Κατατακτήριες (4 επιστημονικά πεδία) & 📑 Εξεταστέα Ύλη
- 🏛️ **763 σχολές & επαγγέλματα** με βάσεις (μόρια) 5ετίας (2022–2026), «βρες σχολές με τα μόριά σου», σύγκριση, φίλτρο πόλης
- 🗓️ Αυτόματο **προσαρμοστικό** πρόγραμμα διαβάσματος (με βάση τις επιδόσεις στα κουίζ) + countdown + εξαγωγή `.ics`
- 📝 Διαγωνίσματα/κουίζ, 🃏 κάρτες μνήμης με **spaced repetition**, «τα λάθη μου»
- 🖊️ Διαδραστικός πίνακας, 📝 σημειώσεις, 🍅 Pomodoro, 🏆 επιτεύγματα/σερί
- 📥 Offline βιβλιοθήκη: ανέβασε τα δικά σου PDF (IndexedDB) — ανοίγουν χωρίς internet
- 🎨 Θέμα σκούρο/φωτεινό, μέγεθος γραμμάτων, πλήρης οθόνη — **PWA, δουλεύει offline**

## Εκδόσεις
- **Online / PWA:** το GitHub Pages link (παραπάνω)
- **Standalone:** `SXOLEIO360_standalone.html` — ένα αρχείο, διπλό κλικ, offline
- **ZIP:** `SXOLEIO360_PWA.zip` — για ανέβασμα σε host (π.χ. tiiny.host)
